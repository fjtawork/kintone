# kintone Clone ランディングページ コンテンツ

## キャッチコピー

**買い切りで使える、ノーコード業務アプリ基盤。**

月額料金なし。自社サーバーで完結。WordPressが動くサーバーさえあれば、今日から業務アプリを作れます。

---

## 誰のためのプロダクトか

- 業務をExcelや紙で回しているが、そろそろシステム化したい小規模チーム
- kintoneに興味はあるが、月額コストが合わない企業
- SaaSにデータを預けたくない（自社管理したい）企業
- IT専任担当者がいなくても、自分たちで業務アプリを作りたい現場

---

## 3つの特徴

### 1. 買い切りライセンス — 月額ゼロ

SaaSではありません。一度購入すれば、何人で使っても追加費用なし。ユーザー数課金もありません。自社サーバーにインストールして、自分たちのペースで運用できます。

### 2. WordPressが動くサーバーで動く

特別なインフラは不要です。PHP + MySQL + Apache — レンタルサーバーの標準構成で動作します。VPSもクラウドも不要。既にWordPressを使っているなら、同じサーバーにインストールできます。

### 3. kintone互換の設計思想

kintone本家と同じ考え方でアプリ・フィールド・レコードを管理。将来kintoneに移行する場合もデータ構造の変換が最小限で済むよう設計しています。ロックインしません。

---

## 主な機能

### 業務アプリ作成（ノーコード）

プログラミング不要で業務アプリを作成。フォームビルダーでドラッグ＆ドロップでフィールドを配置し、すぐに使い始められます。

- テキスト、数値、日付、ドロップダウン、チェックボックスなど豊富なフィールドタイプ
- アプリごとのアイコン・テーマカラー設定
- 一覧表示のカスタマイズ（表示フィールドの選択・並び替え）

### ワークフロー（承認プロセス）

レコードにステータス遷移を設定し、申請→承認→完了のような業務フローを実現。

- ステータスごとの担当者設定（作成者、フィールド参照、固定ユーザー）
- 複数段階の承認フロー（上長→部長→最終承認）
- 差し戻し対応

### レコード管理

作成・編集・削除・検索。ページネーション対応で大量データも快適に操作。

- レコードごとのチャット機能（コメント + @メンション）
- メンション通知（ベルアイコンでリアルタイム通知）
- レコード単位のアクセス制御

### 権限管理

アプリレベル・レコードレベルの細かなアクセス制御。

- superuser / 一般ユーザーの役割分離
- アプリごとの閲覧・編集・削除権限
- レコード単位の公開範囲設定

### 組織管理

部署・役職を登録し、ユーザーに紐付け。承認フローや権限設定に活用できます。

### お知らせ掲示板

全社通知やアナウンスをダッシュボードに掲載。ピン留めで重要なお知らせを上部固定。

### GUIインストーラー

WordPress風のWebベースインストーラーで、ブラウザからDB設定・管理者作成・テーブル作成まで完了。SSHやコマンドラインは不要。

### データベースマイグレーション

バージョンアップ時のDBスキーマ更新を管理画面からワンクリックで実行。技術知識は不要。

## 開発者向け拡張機能

### PHPカスタマイズ（サーバーサイド）

WordPress の `functions.php` と同じ感覚で、サーバーサイドの処理を自由に追加。管理画面のMonaco Editor（VS Code同等）で直接編集。

**利用例:**
- レコード作成時にSlackへWebhook送信
- ステータス変更時にメール通知
- ログイン成功時に監査ログ記録
- 外部APIとのデータ連携

**対応イベント:**
- レコード操作（作成・更新・削除・ステータス変更・コメント追加）
- アプリ操作（作成・更新・削除）
- 認証イベント（ログイン成功・失敗・サインアップ）

### JavaScriptカスタマイズ（フロントエンド）

kintone本家と同じように、JavaScript で画面をカスタマイズ。

- **グローバルJS**: 全ページで実行される共通スクリプト
- **アプリ別JS**: 特定アプリのページでのみ実行されるスクリプト

**利用例:**
- 条件付き書式（期限超過のレコードを赤く表示）
- 入力バリデーションの追加
- 外部サービスとのフロント連携
- 独自UIコンポーネントの追加

## kintone本家との違い

### kintone Clone が優れている点

- **コスト**: 月額ゼロ。10人でも100人でも同じ
- **データ主権**: 自社サーバーにデータが残る。外部に出ない
- **サーバーサイド拡張**: PHPで自由にバックエンド処理を書ける（本家はプラグインのみ）
- **インフラの自由度**: レンタルサーバーでもVPSでもAWSでも動く

### kintone本家が優れている点

- **機能の豊富さ**: 本家は長年の開発で機能が充実
- **サポート**: 公式サポート・コミュニティ・パートナーエコシステム
- **信頼性**: エンタープライズグレードのSLA
- **モバイルアプリ**: 公式モバイルアプリあり
- **連携サービス**: 多数のサードパーティ連携

### つまり

**「まず小さく始めて、大きくなったら本家に移行」** — これがkintone Cloneの提案する使い方です。データ構造を本家と互換に保つことで、移行コストを最小化しています。

## 技術仕様

| 項目 | 内容 |
|------|------|
| サーバー要件 | PHP 8.0以上、MySQL 5.7以上、Apache（mod_rewrite） |
| フロントエンド | 静的HTML/CSS/JS（Node.js不要） |
| 認証方式 | JWT（HS256） |
| API | RESTful JSON API |
| 外部依存 | なし（Composer不要、npm不要） |
| インストール | Webブラウザから5分で完了 |
| アップデート | 管理画面からワンクリック |

---

## 導入の流れ

1. **購入** — ライセンスを購入し、ファイル一式をダウンロード
2. **アップロード** — レンタルサーバーにファイルをFTPアップロード
3. **インストール** — ブラウザからインストーラーにアクセス（5分）
4. **アプリ作成** — ログインして業務アプリを作り始める
